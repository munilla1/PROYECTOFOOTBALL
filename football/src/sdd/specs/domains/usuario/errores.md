# Errores del dominio Usuario

## usuario.email-duplicado
Se intenta registrar un email ya existente.

## usuario.credenciales-invalidas
Email o contraseña incorrectos.

## usuario.no-autorizado
El usuario no tiene permisos para acceder a un recurso.

## usuario.rol-invalido
El rol no coincide con los valores permitidos.

## usuario.membresia-expirada
El usuario intenta acceder a funciones sin membresía activa.

## usuario.progreso-no-encontrado
No existe progreso asociado al usuario.
