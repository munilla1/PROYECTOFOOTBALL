# Dominio: Usuario

## Descripción general
Gestiona la identidad, persistencia y datos principales de cada usuario del videojuego ProyectoFootball.

## Responsabilidades
- Registrar usuarios.
- Autenticar usuarios.
- Guardar progreso del jugador.
- Gestionar roles.
- Gestionar membresías.
