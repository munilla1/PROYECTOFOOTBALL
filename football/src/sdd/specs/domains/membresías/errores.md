# Errores del dominio Membresías

## membresia.expirada
El usuario intenta acceder sin membresía activa.

## membresia.tipo-invalido
El tipo de membresía no coincide con los valores permitidos.

## membresia.stripe-error
Error recibido desde Stripe.

## membresia.no-encontrada
No existe membresía asociada al usuario.
