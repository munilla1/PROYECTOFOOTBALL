# Reglas del dominio Membresías

## R-301: El trial dura 7 días exactos
Desde la fecha de creación del usuario.

## R-302: Si no se elige plan, se pasa a normal automáticamente
Tras finalizar el trial.

## R-303: Stripe gestiona los pagos
ProyectoFootball solo recibe eventos vía webhook.

## R-304: Una membresía expirada bloquea funciones premium
El usuario debe renovar.

## R-305: El tipo de membresía debe ser válido
Valores permitidos: trial, normal, premium.
